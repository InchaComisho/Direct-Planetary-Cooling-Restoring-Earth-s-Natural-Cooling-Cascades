# # Master Repository Index

[日本語版](REPOSITORY_INDEX_ja.md) | [Core DPC README](README.md) | [NOTE: 地球直接冷却](https://note.com/inchacomusho/n/ne956f3a8fdf0)

This file is a management index for the public repositories under `InchaComisho`.

It is an **initial repository-name-based classification**, not a final content-level audit. The goal is to make the growing body of work manageable by grouping repositories into hubs, technical frameworks, philosophy, Artificial Wisdom, climate-causality analysis, creative communication, and archive/cleanup candidates.

## Management Principle

The repository ecosystem should be understood as one open framework:

> Natural Supplementation Science → Direct Planetary Cooling → Earth-cycle regeneration → Artificial Wisdom → sustainable civilization design.

For practical management, this index uses the following status tags:

- **Core Hub**: should be treated as a main entrance.
- **Active Framework**: should remain linked from core hubs.
- **Technical Module**: implementation, model, or specification.
- **Concept / Essay**: explanatory or philosophical document.
- **Narrative / Public Communication**: story, public outreach, or conceptual fiction.
- **Portal / Index**: repository that organizes other repositories.
- **Review / Cleanup Candidate**: name or role should be checked later.
